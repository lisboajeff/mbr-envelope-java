# `br.com.mbr:mbr-envelope` (Java 21)

Biblioteca pura (sem I/O e sem framework de runtime) para construção e evolução de `trace` do Envelope Oficial do **Mercado no Brasil (MBR)**.

## Uso no `pom.xml`

```xml
<dependency>
    <groupId>br.com.mbr</groupId>
    <artifactId>mbr-envelope</artifactId>
    <version>1.0.0</version>
</dependency>
```

## Publicação no GitHub Packages

```bash
mvn -B deploy
```
